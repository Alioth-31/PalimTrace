# Local data / 本地数据

Store permitted input images, models and intermediate outputs locally. The repository tracks source manifests and reviewed derived measurements, not third-party image bytes or credentials.

本目录用于存放经许可的输入图像、模型及中间结果。Git 仅跟踪来源清单与经审核的派生统计，不跟踪第三方原始图像或访问凭证。

See / 参见 [data and privacy policy](../docs/privacy.md).
