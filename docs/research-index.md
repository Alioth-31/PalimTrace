# 研究索引

| 阶段 | 目录（experiments/ 下） | 研究对象与证据等级 |
|---|---|---|
| E01 | `watermark_E01` | 普通信号频带传递预实验；非真实 AIGC |
| E02–E03 | `watermark_study` | 小型自编码器、盲解码与仿射响应；非扩散模型 |
| E04 | `watermark_E04` | 固定载体的跨信道可行域、鲁棒性优化 |
| E05 | `watermark_E05` | 仿射最低误码界、共享预算、尺度不变性 |
| E06 | `watermark_E06` | 格式偏差及未知密钥阴性对照 |
| E07 | `watermark_E07` | 跨条件线性证据；无明确独立性能优势 |
| E08 | `watermark_E08` | 周期统计、谱相干及处理顺序；普通受控图像 |
| E09 | `watermark_E09` | E08 配对重审，非新数据 |
| E10 | `watermark_E10` | 部分历史命题与开放集失效；受控数据 |
| E11 | `watermark_E11` | 鲁棒复合检验、公开边际数据二次分析，非实际融合性能 |
| E12 | `watermark_E12` | 并列秩协方差区间与普通编辑反例 |
| E13 | `watermark_E13` | 七张公开便利样例、分析格点相位；无正式 AIGC 基准 |

研究索引不是发表成果目录。每项结果的适用范围以实验说明和原始记录为准。
