# 隐私与发布边界

研究仓库允许公开。公开范围限经审核的研究代码、实验说明、来源记录和派生统计数据；不得公开项目参与者的个人身份信息、私人邮箱、私人通信、身份或账户凭证、真实密钥、私人目录路径及未经授权的第三方素材。

| 分类 | 管理 |
|---|---|
| 研究代码、研究说明、派生统计 | 审核后纳入 Git；保留失败结果和适用条件 |
| 第三方原始图像、数据集、模型及权重 | 本地保存；Git 只记录来源、许可状态及校验信息 |
| 个人数据、凭证、私人记录 | 不进入 Git；发现后停止发布并审查历史 |
| 实验随机种子、合成测试密钥 | 仅作为非生产研究参数保留 |

提交前检查文件内容、历史、提交作者与元数据。使用项目专用提交身份或 GitHub noreply 地址；不得记录真实私人邮箱。GitHub 账号名称、仓库归属、提交时间等平台公开元数据无法通过删除文件隐藏。启用账号邮箱隐私及阻止暴露私人邮箱的推送设置，按需启用密钥扫描。

.gitignore 只防止误跟踪，不清除已有 Git 历史。发现泄漏时先撤销凭证、评估影响，再专项处理历史；不得默认强制推送。公开不等同于开源许可，不自动发布 Release、授权再分发或邀请协作者。第三方许可需逐项核查。
