# Data and privacy / 数据与隐私

The repository is public. Research code, descriptions, source references and reviewed derived measurements may be published. Personal data, private communications, credentials, local paths and restricted source materials are excluded.

仓库公开。经审核的科研代码、研究说明、来源记录与派生统计可公开；个人数据、私人通信、访问凭证、本机路径和受限制的原始素材不进入 Git。

| Material / 内容 | Handling / 管理方式 |
| --- | --- |
| Code, derived statistics / 代码与派生统计 | Review before commit / 提交前审查 |
| Raw images, model weights / 原图与权重 | Local storage; record provenance and permissions / 本地保存，记录来源与许可 |
| Credentials, personal information / 凭证与个人信息 | Never track / 禁止跟踪 |

Inspect commit metadata as well as file contents; use a GitHub noreply or dedicated project identity. Public account attribution and timestamps remain visible. Ignore rules do not remove tracked files or historical disclosures. If a credential leaks, revoke it before remediation.

提交前检查文件与提交元数据，使用 GitHub noreply 或项目专用身份。公开账号归属与提交时间仍可见。忽略规则不清除已跟踪文件或历史泄漏；凭证泄漏时先撤销凭证。第三方许可逐项核查。
